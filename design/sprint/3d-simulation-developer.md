## 2. Пропуски в съществуващите теми

Колоната „Поетапни 3D = 0“ подценява: hemost, hbcurve, bgroups, hemo, lungmech, gasx, respreg, gfr, tubule, volreg **имат** непрекъснати 3D сцени (`b3*`, `r3Attach`, `k3*`), но без поетапно обхождане. Реални пропуски:

| Тема | Сега | Какво липсва / предложение |
|---|---|---|
| `cardio` | само 2D (Wiggers, PV) | **Най-голям пропуск.** HRA сърце (`hglb1`) в разрез с клапи, които се отварят/затварят по модела; обемът на ЛК мащабира камерата; 4 фази поетапно (`stageViewer`), фазата светва и на PV примката. Всичко е налично (`makeRealHeart`, `heartSprings`). |
| `heart3d` | анатомия, без етапи | Поетапна обиколка: кръвен път ДП→ДК→БА→БВ→ЛП→ЛК→Ao с частици по централни линии (като `gutpath.py`), проводна система, коронарни съдове (вече в `hglb2`). |
| `hemost` | `b3Hemost` (съд, тромбоцити, фибрин) | Етапите (вазоконстрикция → тапа → каскада → фибрин → фибринолиза) да се обвържат с `hsStep`; клетъчният модел (TF-клетка → тромбоцит, тромбинов взрив) като `zCellStg` върху мембрана на тромбоцит. |
| `hbcurve` | 1GZX тетрамер, само R | Липсва T↔R преход: интерполация 2DN2/4HHB (deoxy) ↔ 1GZX/2DN3 по насищането, 2,3-BPG (1B86) в централната кухина, His F8/Fe изместване в „Хем отблизо“. |
| `bgroups` | 2D карта + 3D аглутинация | приемливо. |
| `ecg` | сърце + вектор | Вълна на деполяризацията по миокарда (цвят по време на активация) — най-полезното допълнение. |
| `hemo` | стъклена тръба с еритроцити | Схематично; добре: параболичен профил, аксиално струпване, турбулентност при Re > 2000, паралелни/последователни съдове. |
| `lungmech` | `r3Thorax` + HRA бял дроб | Плеврално пространство/пневмоторакс и сурфактант — два алвеола с различен r (Лаплас). |
| `gasx` | алвеол + капиляр (сфери) | Схематичен; липсва еритроцит с Hb и хлориден обмен (виж т. 3.8). |
| `tubule` | `k3Tub` нефрон в тъкан | Няма клетъчно ниво: клетка на проксималния тубул, ТАL (NKCC2), главна клетка (ENaC/ROMK/AQP2) — сега всички биха били `chan_all`. |
| `volreg` | `k3Vol` тяло + органи | **Надбъбрекът е 4-стенен конус** (`ConeGeometry(…,4)`), ЮГА — схематичен; ADH везикули с AQP2 липсват. |
| `skeletal` | 3D саркомер | приемливо. |

Визуално непълни сцени: генеричните канали (по-горе); кора и малък мозък в барорефлекса/дихателния център (груби HRA мрежи — открита задача 4 в HANDOFF); `hglb3` е художествен модел (да се маркира като „artistic“); `doctor.txt` и `patient.txt` са **байт-идентични** (2,9 MB × 2).

## 3. Предложения за нови модули

Обозначения: [А] анатомично точно, [Ф] физиологично точно, [О] учебно опростяване.

1. **Коронарна циркулация.** Показва: HRA сърце + LCA/LAD/Cx/RCA/вени/синус (`hglb2`, вече заредени); поток с частици по централни линии на артериите; разрез на стената ЛК — субендокард/субепикард. Променливи: ЧСС → дял на диастолата → скорост на частиците в LCA (систолен спад, диастолен пик) [Ф]; аортно диастолно налягане − LVEDP → перфузионен градиент; стеноза (%) → стеснение + цвят на исхемична зона (LAD → предна стена). Взаимодействия: плъзгачи ЧСС/стеноза/аденозин, клик на артерия → територия. Бюджет: съществуващи 2,2 MB GLB, 1 контекст, ≤ 2000 частици InstancedMesh.
2. **Еритропоеза.** Етапи: хипоксия в бъбрека (HIF, перитубулен фибробласт) → EPO (1EER EPO–EPOR) → костен мозък (нише с макрофаг, „еритробластен остров“) → нормобласт → изхвърляне на ядрото → ретикулоцит → `b3RbcGeo`. Желязо: трансферин/TfR1 (1SUV), хепсидин–феропортин (6WBV). Променливи: PO₂/Hb → EPO → скорост на поява на клетки; Fe/B12 → размер (MCV) и цвят (MCH). [О] за нишата, [А] за еритроцита. Бюджет: 3–4 нови mol файла по ≤ 150 KB.
3. **Ентероцит: смилане и всмукване.** Мем: апикален бислой с микровили (InstancedMesh цилиндри), гликокаликс; апикално SGLT1 (`sglt_*` вече има), GLUT5 (4YBQ), PepT1 (7PMY), NHE3; базолатерално GLUT2, NKA (`nka_*`); мастен път: мицела → ЕР → хиломикрон → лимфа (лактеал). Органно ниво: HRA йеюнум (`gutdata`) → въси (процедурни) → клетка (3 мащаба). Променливи: луминална глюкоза → заетост на SGLT1, Na⁺ градиент (NKA вкл./изкл.) → поток 2:1 [Ф стехиометрия]; лактаза дефицит → неразградена лактоза. Бюджет: 4 mol × 150 KB.
4. **Надбъбречна кора — стероидогенеза.** Орган: замяна на конуса с истински надбъбрек (BodyParts3D FMA9604 / HRA), разрез на трите зони. Клетка: LDL/SR-BI → липидна капка → StAR → митохондрия (`mitoCore`, CYP11A1 3N9Y) → гладък ЕР (CYP17A1 3RUK, CYP21A2 4Y8W) → митохондрия (CYP11B1/B2 6M7X/4FDH) → кортизол/алдостерон. Променливи: ACTH → cAMP → StAR активност (поток холестерол); AngII/K⁺ → CYP11B2 в гломерулозата; дефицит на 21-хидроксилаза → отклонение към андрогени. Бюджет: 5 малки mol (≤ 4500 vert).
5. **Яйчник и менструален цикъл.** Орган: HRA яйчник/матка (VH_F_*); процедурни фоликули (MarchingCubes `opt.mc`) — растеж примордиален → антрален → Граафов → овулация → жълто тяло; ендометриумът с дебелина от модела. Променливи: FSH/LH/E2/P4 (вграден 28-дневен модел) → размер на фоликула, дебелина на ендометриума, LH пик → разкъсване [О]. Таймлайн-плъзгач „ден от цикъла“.
6. **Моторни вериги: малък мозък и базални ганглии.** Ресурси: `arcbin` cortex/cerebellum (груби), BodyParts3D: caudate, putamen, globus pallidus, thalamus, substantia nigra, subthalamic n. (FMA, CC BY-SA). Показва директен/индиректен път с импулси по криви (като `barostage`), допамин D1/D2; Паркинсон → по-слаб SNc → по-силен GPi → тъмен таламус. Малък мозък: моховидни/катерещи влакна → Пуркинье (процедурен дендрит в равнина). Променливи: допамин → яркост/честота на импулси по пътищата [О]. Бюджет: ~8 подкорови мрежи по ≤ 3000 триъгълника (общо ≤ 400 KB).
7. **Алвеол и сурфактант.** Разширение на `gasx`/`lungmech`: ацинус с 2 алвеола (r₁ ≠ r₂) и обща бронхиола; пневмоцит II с ламеларни тела → монослой (SP-B, SP-D 1PW9); без сурфактант малкият алвеол се изпразва в големия (P = 2T/r) [Ф по Лаплас]. Плъзгачи: сурфактант %, обем.
8. **Транспорт на O₂/CO₂ в еритроцита.** Клетка `b3RbcGeo` в разрез; Hb (1GZX/2DN2) с T↔R по PO₂ (кривата от `hbCalc`); CO₂ → карбоанхидраза II (3KS3) → HCO₃⁻ през Band 3/AE1 (4YZF) срещу Cl⁻ (хлориден обмен), AQP1 (1J4N), ефект на Haldane/Bohr. Белодробен ↔ тъканен капиляр като два режима. Променливи: PO₂ → насищане (брой O₂ върху хемите) [Ф]; pH/T/2,3-BPG → изместване на P50 → по-ранно освобождаване.

## 4. Технически ограничения и възможности
- **WebGL контексти:** всеки `mk3DView`/`r3Attach`/`stageViewer` създава отделен рендерер; Chrome пази ~16, iOS Safari по-малко — при над лимита най-старият губи контекста. `mk3DView` създава контекста едва при видимост и вика `dispose()`, но само интротата правят `forceContextLoss()`. Теми с 2–3 сцени (starling, respreg, reflex, ans) са рискови. Възможност: един споделен рендерер с `setScissor`/`setViewport` за всички изгледи на страницата или задължителен `forceContextLoss` при `stop`.
- **Тегло:** моделите общо ~33 MB base64 (+33 % спрямо бинарно). `index.html` (1,7 MB), `en.js` (3,2 MB), `gutdata.js` (1,1 MB) и `bladder.js` се зареждат на всяка страница. Синхронен XHR в `getElementById` блокира главната нишка при първо искане на `hglb*/lglb1/lvglb/arcbin`; 4 s след `load` се теглят **всичките** 6 (~8,6 MB) независимо от темата — за телефон с мобилни данни е излишно. Предложение: `.glb`/`.bin` с gzip/brotli от Cloudflare, асинхронно зареждане по тема, meshopt компресия (декодерът е ~20 KB), премахване на дублирания `patient.txt`.
- **LOWGPU:** покрива pixel ratio 1,5 и по-леки липиди; няма LOD за HRA моделите (lglb1 — 153 хил. триъгълника). Нужна втора, децимирана версия (≤ 40 хил.) за телефони и лимит на частиците (≤ 800).
- **Преизползване:** новите клетъчни модули минават изцяло през `zCellStg` + `pdbsurf.py`; органните — през `r3Attach` + HRA GLB; потоците — през `gutpath.py` (централни линии), за да остават частиците вътре в съда. Генеричните `chan_all/pump_all` е добре постепенно да се заменят със специфични модели (ENaC 6BQN, ROMK 7SWJ, NKCC1 6NPL, AQP2 4NEF, H⁺/K⁺-ATPase 5YLU, CFTR 5UAK) — по ~150 KB всеки.
