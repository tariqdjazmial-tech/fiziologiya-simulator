## 1. Модел: променливи, уравнения, параметри

### 1.1 Състояние (`erInit()`)
```js
function erInit(){return{
  t:0,            // дни
  Hb:15.0,        // g/dL — зрял Hb в циркулацията (при нормален плазмен обем)
  Rt:0.125,       // g/dL — ретикулоцитен Hb в кръвта
  E1:0.25,E2:0.25,E3:0.25, // g/dL — костномозъчна верига (BFU-E→CFU-E→еритробласти→норм.)
  EPO:9,          // mU/mL
  Hep:1.0,        // хепцидин, отн. единици (1 = норма)
  Fp:3.0,         // mg — плазмено желязо (трансферин-свързано)
  S:1000,         // mg — запаси (феритин/макрофаги/черен дроб), мъж 800–1000
  MCV:90,         // fL
  Vr:1.0,         // относителен плазмен обем (1 = норма) — за острото кървене
  Bili:0.6,LDH:1.0 // проксита: общ билирубин mg/dL, LDH × норма
}}
```

### 1.2 Константи (КАЛИБРИРАНИ — проверени с `node`, виж §1.6)
```js
const P_={
  J0:0.125,     // g/dL/d базова продукция = 15 g/dL ÷ 120 d
  EPO0:8,       // mU/mL нормално ниво
  kE:0.65,      // наклон на log-EPO спрямо доставката на O₂ (Hb 15→8 g/dL ≈ 90× EPO)
  Href:15,      // g/dL — референтна доставка (задава нормалния Hb)
  nE:0.45,      // EPO→костномозъчен отговор: fE=(EPO/8)^0.45
  fEmax:8,      // максимална еритропоеза 6–8×
  tauM:2.0,     // d — всеки от 3-те костномозъчни компартмента (общо ≈6 d)
  Tr0:1.0,      // d — ретикулоцит в кръвта (до 2,2 d при силен стимул)
  FeHb:173,     // mg Fe на 1 g/dL Hb при 5 L кръв (1 g Hb = 3,47 mg Fe)
  TIBC0:9,      // mg Fe при пълно насищане (≈300 µg/dL × 3 L плазма)
  Fp0:3,        // mg плазмено желязо (≈100 µg/dL) → TSAT 33 %
  S0:1000, kFer:0.125,   // запаси mg; феритин ng/mL = 0,125 × S
  aMax0:0.067,  // базова резорбция ≈ 6,7 % → 1,0 mg/d при 15 mg храна (баланс с загубите)
  FeLoss:1.0, kDep:25, kMob:0.02,
  tauEPO:0.25, tauHep:0.5, tauMCV:20, tauVr:1.0
};
```

### 1.3 Потоци (`erFlux(s,p)`)
```js
// --- кислород и EPO ---
PB   = 760*Math.exp(-alt/7990);                 // alt в метри
PiO2 = 0.2093*(PB-47);
PaCO2= 40 - 10*Math.min(1,alt/4000);            // аклиматизационна хипервентилация
PaO2 = PiO2 - PaCO2/0.8 - 5;                    // ≈95 mmHg на морско ниво, ≈45 при 4000 m
SaO2 = PaO2**2.7/(PaO2**2.7 + 26.6**2.7);       // ≈0.97 / ≈0.82
HbM  = (s.Hb+s.Rt)/s.Vr;                        // ИЗМЕРЕН Hb (плазменият обем има значение!)
DO2  = HbM*SaO2/0.97;                           // доставка на O₂ към бъбречния интерстициум
EPOt = 8*(kid/100)*Math.exp(0.65*(15-DO2))*Math.exp(0.012*(95-PaO2))*(1-0.6*infl/100) + EPOexo;
EPOt = cl(EPOt,0.2,20000);  if(pre==="pv") EPOt = 1.0;   // PV: ендогенният EPO е потиснат
```
```js
// --- желязо (изчислява се ПРЕДИ костномозъчния отговор) ---
TIBC = 9*(1+0.8*cl(1-s.S/500,0,1))*(1-0.3*infl/100);  // трансферин ↑ при дефицит, ↓ при възпаление
TSAT = Math.min(100, 100*s.Fp/TIBC);
Fer  = 0.125*s.S*(1+1.5*infl/100);              // феритинът е и острофазов белтък
ERFE = cl(Math.log10(s.EPO/8)/1.5, 0, 2);       // еритроферон ∝ EPO-драйв
Hept = cl( Math.pow(cl(s.S/1000,0.02,3),1.6) * (1+6*infl/100) * (1+1.0*(1-kid/100)) / (1+3*ERFE), 0.02, 6);
fFP  = cl(2/(1+s.Hep), 0.1, 1.8);               // активен феропортин: =1 при Hep=1
aMax = 0.067*(1+1.5*cl(1-s.S/500,0,1));         // DMT1/DcytB/HIF-2α при празни запаси
Abs  = Math.min(5, fe*aMax*fFP);                // mg/d (норма 1,0–1,5; максимум ≈5)
```
```js
// --- костномозъчен отговор ---
fE   = Math.min(8, Math.pow(s.EPO/8, 0.45))*(1-0.45*infl/100);
fFe  = Math.min(1, (TSAT/(TSAT+10))/0.75);      // =1 при TSAT≥30 %, 0,67 при 10 %, 0,44 при 5 %
Hct  = HbM*3/100;  fV = cl((0.65-Hct)/0.05,0,1);// спирачка при екстремен хематокрит
Pcom = P_.J0*fE*fFe*fV;                         // ангажирани клетки, g/dL/d
if(pre==="pv") Pcom = 0.26*fFe*fV;              // EPO-независима клонова пролиферация
fB   = b12/100;                                 // ефективност на еритропоезата
Rel  = (s.E3/2)*fB;    Ineff = (s.E3/2)*(1-fB); // освободени ретикулоцити / интрамедуларна загуба
Tr   = 1 + 1.2*cl(Math.log10(s.EPO/8)/2, 0, 1); // 1,0 → 2,2 d „стрес-ретикулоцити“
```
```js
// --- разрушаване, загуби, железен поток ---
LifeE = life*(1-0.25*infl/100);                 // възпалението скъсява преживяемостта
Destr = s.Hb/LifeE;                             // g/dL/d
BleedHb = s.Hb*loss/5000;   BleedFe = loss*HbM*0.0347;   // loss в mL/d; 1 mL при Hb 15 ≈ 0,52 mg Fe
Rec  = (Destr+Ineff)*173;                       // mg/d рециклирано (норма ≈22 mg/d)
RelM = Rec*Math.min(1, 0.45+0.55*fFP);          // макрофагът изнася само през феропортина (≈45 % „изтича“ и при пълен блок)
Mob  = 0.02*Math.min(s.S,1200)*(0.3+0.7*fFP)*Math.max(0,1-s.Fp/3);
Upt  = Pcom*173;                                // еритронът взема точно толкова, колкото строи (запазване на масата!)
Dep  = 25*Math.max(0, s.Fp-3);
```
> **Важно за имплементацията:** железният лимит трябва да действа върху `Pcom` (чрез `fFe`), а НЕ върху `Upt`. Ако `Upt` се намали отделно (напр. `×min(1,Fp/3)`), моделът създава желязо от нищото — проверено: +6 mg/ден грешка.

### 1.4 Интегриране (`erStep(s,p,dt)`)
```js
s.EPO += (EPOt-s.EPO)*Math.min(1,dt/0.25);
s.Hep += (Hept-s.Hep)*Math.min(1,dt/0.5);
s.E1  += (Pcom - s.E1/2)*dt;  s.E2 += (s.E1-s.E2)/2*dt;  s.E3 += (s.E2-s.E3)/2*dt;
s.Rt  += (Rel - s.Rt/Tr)*dt;
s.Hb   = Math.max(1, s.Hb + (s.Rt/Tr - Destr - BleedHb)*dt);
s.Fp   = Math.max(0.05, s.Fp + (Abs + RelM + Mob - Upt - Dep)*dt);
s.S   += (Dep + Rec - RelM - Mob - 1.0 - BleedFe)*dt;
if(s.S<0){ s.Fp = Math.max(0.05, s.Fp + s.S); s.S = 0; }   // дефицитът се тегли от плазмата, не изчезва
if(s.S>4000) s.S = 4000;
retPct = 100*s.Rt/(s.Hb+s.Rt);
MCVt   = cl(90 - 26*(1-fFe) + 32*(1-fB) + 3*Math.min(2,retPct/5), 58, 128);
s.MCV += (MCVt-s.MCV)*dt/20;
s.Vr  += (1-s.Vr)*dt/1.0;
s.Bili += (0.3 + 0.3*(Destr/0.125) + 0.45*(Ineff/0.125) - s.Bili)*dt;   // mg/dL
s.LDH  += (1 + 1.2*(Destr/0.125-1) + 2.5*(Ineff/0.125) - s.LDH)*dt;     // × горна норма
s.t += dt;
```
Остро кървене (пресет `bleed`, **еднократно** при избора на пресета):
```js
s.Hb*=0.8; s.Rt*=0.8; s.Vr=0.80; s.S=Math.max(0,s.S-250);  // 1 L = 20 % от обема ≈ 500 mg Fe, половината от запасите покриват
```
Числена стабилност: `dt ≤ 0.02 d` (заради `kDep=25`); при `dt>0.04` плазменият железен пул осцилира.

### 1.5 Изходни величини
```js
Hct  = HbM*3;                                  // % (правилото „3×Hb“)
retAbs = retPct/100 * RBC*1000;                // ×10⁹/L (норма 25–75)
RPI  = retPct*(HbM/15)/Tr;                     // норма ≈1; при анемия <2 = неадекватен отговор
RBC  = HbM*10/(s.MCV*0.33);                    // ×10¹²/L (MCHC ≈33 g/dL)
MCH  = s.MCV*0.33;                             // pg
```

**Динамика на `bleed` (1 L), проверена:** ден 0 Hb 15,1 (непроменен) → ден 1 **13,1** → ден 2–5 **12,3** (надир) → ден 10 12,6 → ден 21 13,4 → ден 42 14,3 → ден 60 14,7. EPO: 8 → 24 (ден 1) → пик 48 (ден 5) → 13 (ден 42). Ретикулоцити: 0,8 % → пик 2,0–2,2 % (ден 8–12). Хепцидин: 1,0 → 0,2 (еритроферон). Феритин 126 → 44. Резорбцията расте до 2,5–3 mg/d.

**Контролни проверки за имплементатора**
1. `norm` е стабилен ±2 % за 300 дни (Hb 15,1; S 1010).
2. Запазване на желязото: `S + Fp + 173×(Hb+Rt+E1+E2+E3)` се променя само с `Abs − 1 − BleedFe` (допустима грешка <1 mg/ден).
3. `perni` → връщане на `b12:100` дава ретикулоцитна криза (пик на 5–8 ден) и Hb +0,8–1,2 g/dL/седмица.
4. `ckd` → `kid:100` нормализира Hb за 6–8 седмици, като феритинът и TSAT падат (функционален железен дефицит).
5. `ida` → `loss:0, fe:20`: първо се качва Hb (седмици), а феритинът се пълни последен (месеци) — обратен ред на изчерпването.

### 3.4 2D рисунка (`draw`)
Три хоризонтални ивици + железен кръговрат:
1. **Бъбрек (горе вляво)** — перитубулен фибробласт, индикатор PaO₂/SaO₂, HIF-2α „лампичка“; стрелка `EPO` с дебелина ∝ log(EPO) към мозъка.
2. **Костен мозък (център)** — верига кутии: `хемоцитобласт → BFU-E → CFU-E → проеритробласт → базофилен/полихроматофилен/ортохромен нормобласт → (изхвърляне на ядрото) → ретикулоцит`; запълването на всяка кутия ∝ E1/E2/E3; зелена стрелка „освободени“ ∝ Rel, червена пунктирана „интрамедуларна деструкция“ ∝ Ineff (видима само при b12<100).
3. **Кръв (долу)** — поле с кръгчета: брой ∝ Hb, цвят по-блед при нисък MCHC, диаметър ∝ MCV; отделни „ретикулоцити“ със синя мрежа, брой ∝ retPct; стрелка към `макрофаг на далака` (дебелина ∝ Destr) и стрелка „кръвозагуба“ навън ∝ loss.
4. **Железен кръговрат (дясна колона)** — черва (DMT1 апикално → феропортин базолатерално с катинар ∝ Hep) → трансферин (запълване ∝ TSAT) → мозък; макрофаг (рециклиране 22 mg/d, феропортин с катинар) → трансферин; черен дроб: феритинов резервоар (височина ∝ S) + хепцидинова стрелка към катинарите; стрелки IL-6 ⊕ и еритроферон ⊖ към хепцидина.

1. **Цели на урока / Learning objectives** (`LI`)
   - Да обясниш веригата хипоксия → HIF-2α → EPO → BFU-E/CFU-E → ретикулоцит → еритроцит и нейните времена. / Explain the chain hypoxia → HIF-2α → EPO → BFU-E/CFU-E → reticulocyte → red cell and its time course.
   - Да проследиш едно атомче желязо: храна → DMT1 → ентероцит → феропортин → трансферин → еритробласт → макрофаг → отново трансферин. / Follow one iron atom: food → DMT1 → enterocyte → ferroportin → transferrin → erythroblast → macrophage → transferrin again.
   - Да обясниш защо хепцидинът е „централният клапан“ и как го местят запасите, възпалението и еритроферонът. / Explain why hepcidin is the central valve and how stores, inflammation and erythroferrone move it.
   - Да различиш анемиите по MCV, ретикулоцитен индекс, феритин и TSAT. / Distinguish the anaemias by MCV, reticulocyte index, ferritin and TSAT.
   - Да предскажеш какво става с Hb, EPO и желязото при кървене, височина, ХБЗ, хемолиза и дефицит на B12. / Predict Hb, EPO and iron after bleeding, at altitude, in CKD, haemolysis and B12 deficiency.

2. **Норма: числата / Normal values**
   - Hb ♂ 13,5–17,5 g/dL, ♀ 12–16; Hct ≈ 3×Hb (♂ 40–52 %, ♀ 36–48); еритроцити 4,2–5,9×10¹²/L.
   - MCV 80–100 fL, MCH 27–33 pg, MCHC 32–36 g/dL; ретикулоцити 0,5–1,5 % (25–75×10⁹/L).
   - Живот на еритроцита 120 дни → ≈0,8 % от масата се подменя дневно (≈2×10¹¹ клетки, 2,4 млн/s).
   - Съзряване в мозъка ≈5–7 дни; ретикулоцитът остава 1 ден в мозъка и ≈1 ден в кръвта (при силен стимул излиза по-рано и живее 2–2,5 дни в кръвта — „стрес-ретикулоцити“).
   - EPO 4–20 mU/mL; t½ 6–9 h; 90 % се прави от перитубулни фибробласти на бъбречната кора, 10 % от черния дроб.
   - Общо телесно желязо 3–4 g: ≈2,5 g в хемоглобина, 1 g запаси (феритин/хемосидерин), 300 mg миоглобин/ензими, 3 mg в плазмата върху трансферина.
   - Резорбция 1–2 mg/ден (макс. ≈5), облигатни загуби 1 mg/ден (♀ +0,5 от менструация); рециклиране от макрофагите ≈20–25 mg/ден.
   - Феритин 30–300 ng/mL (1 ng/mL ≈ 8–10 mg запас); TIBC 250–400 µg/dL; серумно желязо 60–160 µg/dL; TSAT 20–45 %.
   - B12: запас 2–5 mg в черния дроб, нужда 2 µg/ден → дефицитът отнема 3–5 години. Фолат: запас за 3–4 месеца.

3. **Механизмът стъпка по стъпка / The mechanism step by step** (`<ol>`)
   1. Бъбречните перитубулни фибробласти измерват не Hb, а **доставката на O₂** (Hb × SaO₂ × кръвоток). При хипоксия пролил-хидроксилазите спират (нужен им е O₂), **HIF-2α** не се разгражда от VHL и включва EPO-гена.
   2. EPO расте **логаритмично**: при спад на Hb от 14 към 7 g/dL се покачва ≈100 пъти (до 1000 mU/mL). Затова „нормален“ EPO при тежка анемия е патологичен.
   3. EPO се свързва с EPO-рецептора (JAK2/STAT5) на **CFU-E и проеритробластите** и действа главно антиапоптотично — спасява клетки, които иначе биха загинали; затова ефектът му е бърз, но ограничен (6–8×).
   4. Еритробластът натрупва хемоглобин (синтез на хем в митохондрията: сукцинил-КоА + глицин → ALA → протопорфирин IX + Fe²⁺ чрез фероxелатаза).
   5. Ортохромният нормобласт **изхвърля ядрото** → ретикулоцит с остатъчна рРНК (оттам мрежата при суправитално оцветяване).
   6. Ретикулоцитът излиза в кръвта и за ≈24 h губи РНК и митохондрии → зрял двойновдлъбнат диск без ядро, който не може да синтезира протеини и живее на гликолиза.
   7. След 120 дни клетката се износва (загуба на мембрана, експозиция на фосфатидилсерин) и макрофагите в далака я фагоцитират: глобинът → аминокиселини, желязото → обратно в трансферина, хемът → билирубин.
   8. **Желязото**: храна (хем-Fe по-добре резорбируемо; не-хем Fe³⁺ се редуцира от DcytB) → **DMT1** апикално → ентероцит → **феропортин** базолатерално + хефестин (окислява до Fe³⁺) → **трансферин** (2 атома) → TfR1 ендоцитоза в еритробласта.
   9. **Хепцидинът** (черен дроб) се свързва с феропортина, предизвиква интернализацията и разграждането му → желязото остава заключено в ентероцита (който после се олющва) и в макрофага.

4. **Регулация / Regulation**
   - **Отрицателна обратна връзка по O₂**: ↓доставка на O₂ → ↑EPO → ↑еритропоеза → ↑Hb → ↑доставка. Контурът е бавен: ретикулоцитите се виждат на 3–5-ия ден, Hb расте с ≈0,1–0,2 g/dL дневно (максимум ≈1 g/dL на седмица).
   - **Какво вдига EPO освен анемията**: височина, белодробна болест, десен-ляв шънт, сърдечна недостатъчност, карбоксихемоглобин, андрогени, EPO-секретиращи тумори (бъбрек, хемангиобластом).
   - **Хепцидин ↑**: пълни запаси (чрез BMP6/HJV–SMAD в хепатоцита), **възпаление (IL-6 → STAT3)**, намалена бъбречна екскреция.
   - **Хепцидин ↓**: празни запаси, хипоксия, **еритроферон (ERFE)** от еритробластите при силен EPO-драйв, тестостерон. Затова при кървене, хемолиза и таласемия хепцидинът е нисък и резорбцията расте (при таласемия — до желязно претоварване).
   - **Резорбцията** се регулира и от самия ентероцит: при дефицит HIF-2α вдига DMT1 и DcytB — но максимумът е ≈5 mg/ден, затова загуба >5 mg/ден винаги води до дефицит.
   - **Нужно за еритропоезата**: желязо, B12 и фолат (ДНК), B6 (хем), белтък, мед, тироксин, андрогени.

5. **Клинично значение / Clinical relevance**
   - **Класификация по MCV**: микроцитна (желязодефицит, таласемия, сидеробластна, част от ACD) · нормоцитна (остра кръвозагуба, ХБЗ, ACD, хемолиза, апластична) · макроцитна (B12/фолат — мегалобластна; алкохол, чернодробна болест, хипотиреоидизъм, ретикулоцитоза — немегалобластна).
   - **Класификация по ретикулоцитен индекс (RPI)**: RPI >2–3 = периферна загуба (хемолиза, кървене); RPI <2 при анемия = проблем в мозъка (дефицит на субстрат, EPO или стволови клетки).
   - **Желязодефицит vs ACD**: феритин ↓↓ vs ↑; TIBC ↑ vs ↓; хепцидин ↓ vs ↑; разтворим TfR ↑ vs N. При комбинация → феритин 30–100 + sTfR ↑.
   - **Желязодефицит при мъж или жена след менопауза = кървене от ГИТ, докато не се докаже друго** (колоноскопия).
   - **Пернициозна анемия**: автоантитела срещу париеталните клетки/вътрешния фактор; неврологични прояви (фуникуларна миелоза) — фолатът коригира кръвната картина, но НЕ неврологията, затова винаги се изключва B12 дефицит преди фолат.
   - **ХБЗ**: ЕСА + желязо; целеви Hb 100–115 g/L (KDIGO 2012) — пълната корекция до норма увеличава инсулти и тромбози.
   - **Полицитемия**: PV (EPO нисък, JAK2+, лечение — венесекции, Hct <45 %) vs вторична (EPO висок) vs относителна (дехидратация — намален плазмен обем при нормална еритроцитна маса).
   - **Хемохроматоза** (HFE): хепцидинът е неадекватно нисък при пълни запаси → резорбцията не се изключва → натрупване 20–40 g желязо.
   - **Острата кръвозагуба** в първите часове дава НОРМАЛЕН Hb — тежестта се оценява по пулс, налягане и лактат, не по хемоглобина.

6. **Чести заблуди / Common misconceptions**
   - „Веднага след кръвоизлив Hb пада.“ — Губят се клетки и плазма в еднакво съотношение; концентрацията пада едва след хемодилуцията (12–72 h).
   - „Ретикулоцити 2 % значи добър отговор.“ — 2 % при Hb 7 g/dL е абсолютно нисък брой; смятай абсолютен брой или RPI.
   - „Високият феритин изключва желязодефицит.“ — Феритинът е острофазов белтък; при възпаление праговете се вдигат (<100 ng/mL при възпаление вече подозрително).
   - „При възпаление желязото липсва.“ — Желязото е налице, но е заключено от хепцидина; интравенозното желязо работи зле, докато трае възпалението.
   - „Бъбрекът мери хемоглобина.“ — Мери доставката на O₂; при CO-интоксикация или десен-ляв шънт Hb е нормален, а EPO расте.
   - „EPO прави нови стволови клетки.“ — Действа главно като фактор за преживяемост (антиапоптоза) на вече ангажираните CFU-E.
   - „Анемията при ХБЗ е от липса на желязо.“ — Главната причина е липсата на EPO; желязото е допълнителен фактор (хепцидин ↑, загуби при диализа).
   - „Макроцитозата винаги е от B12/фолат.“ — Силната ретикулоцитоза, алкохолът и хипотиреоидизмът също вдигат MCV.

7. **Опростено в модела / Simplified in the model**
   - Една усреднена „порция“ хемоглобин вместо отделни клетки; съзряването е верига от 3 компартмента с τ = 2 дни (средно 6 дни) вместо дискретни стадии.
   - Плазменият обем се възстановява с една константа (τ = 1 ден); няма преразпределение на течности, няма сърдечно-съдова компенсация (тахикардия, 2,3-ДФГ, изместване на кривата на дисоциация).
   - Желязото е в 3 компартмента (плазма, запаси, хемоглобин); миоглобинът и ензимното желязо липсват; загубата при кървене се вади направо от баланса.
   - Хепцидинът е една алгебрична функция на запаси/възпаление/ERFE, без BMP6-SMAD кинетика; бъбречният клирънс е грубо приближен.
   - B12/фолат влизат само като „процент ефективна еритропоеза“ + MCV; няма неврология, няма хомоцистеин/метилмалонова киселина.
   - Няма далачна секвестрация, няма имунна хемолиза с комплемент, няма левкоцити и тромбоцити; ЕСА е постоянна концентрация, не фармакокинетика.

## 5. Тестове (`tests`, 14 × 4 опции)

   Експл.: Феропортинът е единственият износител на желязо от ентероцита, макрофага и хепатоцита. / Ferroportin is the only iron exporter of enterocytes, macrophages and hepatocytes.

   Експл.: IL-6 → хепцидин ↑ (желязото е заключено) и феритинът е острофазов; трансферинът е негативен острофазов белтък. / IL-6 → hepcidin ↑ (iron locked) and ferritin is an acute-phase protein; transferrin is a negative acute-phase protein.
8. Коя находка най-добре различава желязодефицита от таласемия и от ACD? / Which finding best separates iron deficiency from thalassaemia and ACD?

   Експл.: Микроцитозата е обща; само при истински дефицит запасите са празни и трансферинът е увеличен. / Microcytosis is shared; only in true deficiency are stores empty and transferrin increased.
9. Защо при тежка хемолиза феритинът и TSAT се покачват? / Why do ferritin and TSAT rise in severe haemolysis?

   Експл.: Желязото не напуска тялото при хемолиза; губи се само при кървене. / Iron does not leave the body in haemolysis; it is lost only with bleeding.

12. Най-ранният лабораторен белег на изчерпващо се желязо е: / The earliest laboratory sign of depleting iron is:
    [Нисък хемоглобин | Нисък MCV | Нисък феритин | Висок RDW] → **2**
    Експл.: Последователност: запаси (феритин) → транспорт (TSAT, TIBC) → еритропоеза (MCV, RDW) → Hb. / Sequence: stores (ferritin) → transport (TSAT, TIBC) → erythropoiesis (MCV, RDW) → Hb.

    [EPO остава висок, Hb не се променя | EPO скача, после спада, докато Hb и Hct растат | EPO и Hb падат | Хепцидинът расте] → **1**
    Експл.: Пикът на EPO е на 1–2-ия ден; когато доставката на O₂ се възстанови чрез по-висок Hb, EPO се връща близо до нормата; еритроферонът потиска хепцидина, за да освободи желязо. / The EPO peak is on day 1–2; once O₂ delivery is restored by a higher Hb, EPO returns near normal; erythroferrone suppresses hepcidin to release iron.

    Експл.: Автономната клонова пролиферация (JAK2 V617F) потиска ендогенния EPO; при всяка вторична причина EPO е висок. / Autonomous clonal proliferation (JAK2 V617F) suppresses endogenous EPO; in every secondary cause EPO is high.

   Подсказка: Запасите са буферът: първо феритин, после TSAT, последен Hb. / Stores are the buffer: ferritin first, then TSAT, Hb last.

   Подсказка: При възпаление феритинът е висок, а желязото пак не стига — заключено е. / With inflammation ferritin is high, yet iron is still unavailable — it is locked away.

   Подсказка: Съзряването отнема 5–7 дни — същото закъснение важи и за лечението. / Maturation takes 5–7 days — the same lag applies to treatment.
5. „Пресет **ХБЗ**: вдигни бъбречната продукция на EPO до 100 %, без да пипаш желязото. Какво става?“ / "**CKD** preset: raise renal EPO production to 100 % without touching iron. What happens?"
