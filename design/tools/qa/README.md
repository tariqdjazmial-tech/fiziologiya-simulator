# Визуална проверка на симулациите (Playwright)

- `pw.js` — отваря тема с тестов режим, без въведение, three.js от локален пакет (`SP/three/package`, `npm pack three@0.128.0`).
- `t_sweep.js тема…` — минава през всеки поетапен 3D изглед стъпка по стъпка и снима (`SP/sheets/`); грешките от конзолата → `тема.json`.
- `t_one.js тема N етикет` — снимка след N натискания на „Следваща стъпка“ (`V=` индекс на изгледа).
- `sheet.py SP префикс…` — контактен лист от снимките.

Пускане: `cd site && python3 -m http.server 8765`, после `SP=<папка> NODE_PATH=$(npm root -g) node t_sweep.js ap synapse`.
Известни ограничения: стъпките се въртят в кръг (спира на 10 снимки); подсцените (бутони над изгледа) не се обхождат.
