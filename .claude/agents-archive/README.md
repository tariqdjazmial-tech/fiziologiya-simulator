# Архив на агенти

Тези агенти не се ползват в конвейера (виж CLAUDE.md). Пазят се за справка.
- `medical-researcher` → проучването на източници е част от `physiology-spec`.
- `simulation-engineer` → моделът се пише от главната сесия и се тества с `design/tools/spec-test.mjs`.

За да върнеш агент: премести файла обратно в `.claude/agents/`.
